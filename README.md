# IBPE Landing Page

Landing page institucional do IBPE — Instituto Brasileiro de Pesquisa em Emergência, construída com Next.js, TypeScript e Tailwind CSS.

## Como rodar

```bash
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.

## Logo

Coloque o arquivo da marca em:

```bash
public/logo-ibpe.png
```

Se o arquivo não existir, o site mostra um fallback textual estilizado.
